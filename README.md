# SAIL - Student AI Lab

SAIL is an eight-hour, hands-on artificial intelligence curriculum for students ages 14-18. The student portal provides five interactive modules with embedded slides, concept notes, worksheets, and links to online labs.

## Files

- `index.html` - The complete student portal. It runs in a browser without a build step.
- `SAIL_Student_Workbook-Final.pdf` - The accompanying student workbook.

## Run locally

Open `index.html` in a modern browser. An internet connection is needed for the embedded Figma slides, Google Fonts, and linked learning tools. Course progress is saved in the browser's local storage.

## Publish with GitHub Pages

In the `sail` repository on GitHub, open **Settings > Pages**, choose **Deploy from a branch**, select the `main` branch and `/ (root)` folder, then save. The portal will be served from `index.html` at the published site URL.
